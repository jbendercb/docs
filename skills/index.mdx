## What these are

A **skill** is a set of instructions an agent loads when it recognizes the task. These 19 skills
package the [playbooks](/playbooks/index) into that format, so an agent runs the method instead of
you reading it and relaying the steps.

They are the same methods, in a form an agent consumes directly. The playbooks remain the place to
understand *why* a method works; the skills are how an agent *executes* it.

## Discovery

This site publishes an Agent Skills discovery catalog. An agent that supports the convention finds
every skill below, with a `sha256` digest per skill for integrity:

```
https://docs.corestory.ai/.well-known/agent-skills/index.json
```

Individual skills are served at `/.well-known/agent-skills/{name}/SKILL.md`.

## Installation

The skills are MIT licensed and published at
[CoreStoryAI/agent-skills](https://github.com/CoreStoryAI/agent-skills), which also carries the
Claude Code and Codex plugin packages.

<CodeGroup>

```bash Claude Code
claude plugin marketplace add CoreStoryAI/agent-skills
claude plugin install corestory@corestory
```

```bash Codex
codex plugin marketplace add CoreStoryAI/agent-skills
codex plugin add corestory@corestory
```

```bash Any agent (skills only)
gh skill install CoreStoryAI/agent-skills --all --agent codex --scope user
```

</CodeGroup>

<Warning>
**The CoreStory MCP URL is per-organization**, so no repository can ship a working one. Claude Code
prompts for yours during install. Codex needs it added manually:

```bash
codex mcp add corestory --url https://app.corestory.ai/mcp/your-org-slug-123456789
```

Copy your URL from **CoreStory → Settings → IDE Integrations**. See
[MCP Server Setup](/getting-started/mcp-server-setup).
</Warning>

## How these relate to the playbooks

Every skill traces to a public playbook, and the repository's `SOURCES.md` records the provenance of
each one along with every deliberate difference from its source. The most important of those: an
installed skill does not commit, post to a ticket, or write to Jira or Linear unless you ask it to,
where some playbooks describe those as defaults. An agent acting on your repository should not take
an outward-facing action you did not request.

<Note>
Skill content lives in the [public repository](https://github.com/CoreStoryAI/agent-skills) and is
synced into this site, so the served files and the installable files never drift.
</Note>
