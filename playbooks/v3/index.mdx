CoreStory v3 builds a local map of a codebase, from applications down to business rules, each traced to the code behind it, and serves that map to coding agents over MCP. The v3 skills are short recipes that tell an agent which CoreStory v3 tools to call, in what order, and which file to write the result to.

These pages sit beside the hosted playbooks. The hosted playbooks are unchanged and remain available under [Playbooks](/playbooks/index).

## What a v3 skill is

A skill is a folder with a `SKILL.md` file that an agent loads when the task matches. Every v3 skill follows the same pattern:

- **Preflight first.** It calls `status` and `corpus_info`. If the repository is not indexed, or the last ingest failed, it stops and relays the next step. It never runs `init` or `ingest` without your explicit OK.
- **Rules are leads until checked.** It reads the cited source lines before relying on a rule, and cites only lines it read.
- **Output goes to a file in your repository**, such as `BUG-NOTES.md` or `RULES.md`, not to the chat. Each file ends with a `Not verified` section.
- **CoreStory does not run code.** It reads and indexes it. Any test results come from commands the agent ran.

For the tools themselves and their limits, see [Using CoreStory v3](/playbooks/v3/using-corestory).

## Install CoreStory v3

<Steps>
  <Step title="Download the command-line tool">
    Get the `corestory` command-line tool from [get.corestory.ai](https://get.corestory.ai/). Builds are published for macOS (Apple silicon), Linux (x64) and Windows (x64). Put `corestory` on your PATH and check it with `corestory --version`.
  </Step>
  <Step title="Run setup yourself">
    Run `corestory setup` in your own terminal. It is interactive: you accept the Terms of Use and Privacy Policy, choose your telemetry setting, and add a model key (OpenAI, Azure OpenAI or Anthropic). An agent should never do this for you, and other commands refuse to run until setup is done.
  </Step>
  <Step title="Index the repository">
    From the repository folder, run `corestory init` and then `corestory ingest`. Ingest calls your model provider and can cost money, so run it yourself. Add `.corestory/` to your `.gitignore`.
  </Step>
  <Step title="Connect your agent">
    `corestory mcp` is a stdio MCP server for the repository it is started in. It takes no path argument, so it must start from the repository folder. See the options below.
  </Step>
</Steps>

### Connect your agent

<Tabs>
  <Tab title="Claude Code plugin">
    ```bash
    claude plugin marketplace add corestoryai/agent-skills
    claude plugin install corestory-local@corestory
    ```
    The plugin starts `corestory mcp` in the folder Claude Code is working in, and installs the skills and the session hook described below.
  </Tab>
  <Tab title="GitHub Copilot">
    Create `.mcp.json` at the repository root. This also works for Claude Code without the plugin.
    ```json
    {"mcpServers":{"corestory":{"type":"stdio","command":"corestory","args":["mcp"]}}}
    ```
  </Tab>
  <Tab title="Cursor">
    Create `.cursor/mcp.json`. The `cd` makes the server start in your workspace folder.
    ```json
    {"mcpServers":{"corestory":{"type":"stdio","command":"sh","args":["-c","cd \"$0\" && exec corestory mcp","${workspaceFolder}"]}}}
    ```
  </Tab>
  <Tab title="Codex">
    Add this to `~/.codex/config.toml`, with the absolute path of the repository.
    ```toml
    [mcp_servers.corestory]
    command = "corestory"
    args = ["mcp"]
    cwd = "/absolute/path/to/your/repository"
    ```
  </Tab>
</Tabs>

Outside the Claude Code plugin, the skills themselves are installed from the [agent-skills repository](https://github.com/CoreStoryAI/agent-skills). A machine-readable catalog is at [get.corestory.ai](https://get.corestory.ai/.well-known/agent-skills/index.json).

### How the agent finds the skills

Agents use the skills far more reliably when pointed to them than when left to discover them.

- **Claude Code plugin.** The plugin ships a `SessionStart` hook that adds one line to the agent's context, pointing it to the CoreStory skills for code changes and codebase questions.
- **Everywhere else.** Put the same line in `CLAUDE.md` or `AGENTS.md`:

```text
For any change to this code or any question about it, first use the matching CoreStory skill (implement-feature, bug-resolver, generate-tests, corestory-ask) before editing or answering.
```
